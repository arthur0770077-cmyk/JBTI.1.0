# JBTI 调研记录

调研日期：2026-09-13。本文只记录可核对的产品模式、开源实现和测量原则；没有把竞品的宣传语当成独立科学证据。

## 在线产品观察

| 产品 | 观察到的体验 | 可借鉴 | 不采用 |
| --- | --- | --- | --- |
| [16Personalities](https://www.16personalities.com/en/personality-test) | 大入口、低学习成本、类型化结果和大量延伸阅读 | 让用户快速进入作答；结果分层阅读 | 其品牌、插画、题目、类型名称与文案 |
| [Truity Big Five](https://www.truity.com/test/big-five-personality-test) | 无需注册即可开始并看到结果概览；登录后可保存进度；详细报告另行解锁 | 开始前明确免费范围与保存条件 | 用付费墙切断首个完整结果 |
| [TraitLab](https://www.traitlab.com/home) | 保存进度；连续特质图；详细解释与分享资料 | 连续分数、误差意识、可继续阅读的层级 | 把多套框架一次塞进 MVP |
| [Crystal](https://www.crystalknows.com/personality-test) | 先说明完成时间、题量和无需注册；按使用目标介绍不同框架 | 降低开始成本；把结果与实际沟通情境连接 | 未经独立核验的准确性营销 |
| [MoodyWonder Work Style](https://www.moodywonder.com/tests/work-style) | 20 题、键盘 1–5 作答、即时结果和分享卡片 | 桌面快捷键、可分享结果、清晰时间预期 | 把工作风格结论扩大为完整人格诊断 |

共同模式：首屏给出时间和题量；单题界面减少同时阅读负担；完成进度持续可见；结果先给一句话与视觉摘要，再进入详细解释；分享卡片比完整报告更适合社交传播。

JBTI 的取舍：采用单题作答、键盘快捷键、本机续答、连续分数、分层结果与本地分享卡片；不复制竞品资产，不要求登录，不隐藏核心结果，不宣称临床或职业预测能力。

## 专业知识来源

- [International Personality Item Pool](https://ipip.ori.org/)：公开领域人格题项、量表和计分资料。JBTI 学习其透明计分思路，但首版题目为原创，也没有声称等同于 IPIP 量表。
- [APA / AERA / NCME 测验标准](https://www.apa.org/science/standards.html)：正式测验应提供与用途相匹配的效度、信度、公平性和解释证据。
- [COSMIN](https://www.cosmin.nl/)：内容效度、结构效度、内部一致性、重测信度和测量误差是不同的测量属性，不能用单一系数替代全部验证。
- [量表开发与验证实践指南](https://pmc.ncbi.nlm.nih.gov/articles/PMC11798685/)：题项需要覆盖构念，避免极端和混合问题；反向表述可能引起理解混乱；题量和疲劳需要平衡。
- [IPIP 50 题施测示例](https://www.ipip.ori.org/New_IPIP-50-item-scale.htm)：展示正向与反向计分的透明做法。

首版把“反向计分”实现为对同一双向维度另一端的正面情境描述，避免简单添加“不”字造成语义混乱。

## 证据、推断与假设

### 有资料支持

- 人格测量结果需要明确具体用途与解释边界。
- 连续维度能保留接近中点的信息。
- 信度、效度与公平性需要分别收集证据。
- 公共领域不等于已经适用于所有语言、年龄和文化情境，翻译与改写仍需验证。

### 产品推断

- 40 题、约 6–8 分钟可能在覆盖四个维度和完成负担之间取得适合 MVP 的平衡。
- 单题、进度、数字键与自动续答可能降低中途退出。
- “类型代码 + 连续条形图 + 中间带提醒”可能减少绝对化理解。

### 尚待实验

- 四个原创维度是否具有可区分的因子结构。
- 中文题项是否被 15–25 岁目标用户按预期理解。
- 题项区分度、内部一致性、重测稳定性和群体公平性。
- 50% 附近的解释阈值是否合理。
- 暂定类型名称是否好记、愿意分享且不过度正向。

## 建议的验证顺序

1. 用 8–12 位目标用户做逐题认知访谈；发现多人误解的题立即重写。
2. 小范围预测，检查缺失、完成时间、极端作答、题项分布与题项相关；先删改表现异常题。
3. 获得足够样本后探索维度结构与内部一致性；不稳定则停止对外宣传准确性。
4. 用独立样本确认结构，补做重测和群体差异分析。
5. 最后才校准阈值、结果名称和对外表述。
