# JBTI 16 型命名工作台

当前名称都是可替换的编辑占位。最终名称由产品负责人决定，修改入口集中在 `lib/profiles.ts`，不会影响题目、得分或类型代码。

面向 15–25 岁用户的命名建议：

- 4–6 个汉字，读起来有画面，但不要像职业定论。
- 能做成一句自然的分享文案，例如“我是 CPIR 坐标绘制者”。
- 16 个名称的吸引力尽量平衡，避免某些类型明显像“赢家”或“反派”。
- 少用“天才、王者、社恐、疯子”等标签，避免把短期状态固定成人格。
- 每个名称至少经过记忆度、理解偏差、分享意愿三项小样本测试。
